Client-side temperate phage integration-site screening

attP / attB Finder

Drop annotated phage GenBank files and host_index.json files to predict candidate phage attP and host attB sites near tRNAs/tmRNAs/rRNAs, serine-integrase CDS hotspots such as groL/groEL, and, optionally, across indexed host genome chunks.

Static GitHub Pages app No server upload. Use host_index.json for large bacterial genomes.

1. Input files

Phage files should preferably be annotated GenBank files containing an integrase CDS. Multi-record phage FASTA files are also accepted; each FASTA record is treated as a separate phage and searched as a whole-phage query because FASTA has no integrase annotation. For large bacterial genomes, first run the included Python script in tools/ to create host_index.json, then upload that JSON file here. Small bacterial GenBank or FASTA files can still be used directly, but host_index.json is the recommended path.

2. Analysis settings

The score combines exact shared core length, optional serine small-core/stem support, k-mer support, feature-neighborhood proximity, and whether the match is in the expected integrase-proximal phage window. It is a prioritization score, not experimental proof. For host_index.json files built without global chunks, turn off broader search or expect the app to skip that step. For indexed global chunks, keep “Maximum global candidates” modest.

How to interpret this

High-confidence tyrosine-integrase candidates usually have a clear exact core match of roughly 20–50 bp between the phage integrase-proximal region and a bacterial locus, often overlapping or immediately adjacent to a tRNA/tmRNA/rRNA. Serine-integrase candidates may have much smaller shared cores; the new serine mode therefore also looks for a short shared core supported by inverted-complement arms/stem-like symmetry and it prioritizes known CDS hotspots such as groL/groEL.

Large bacterial GenBank files should be converted before upload. Run tools/build_host_index_interactive.py on your computer to create host_index.json. The browser then searches compact tRNA/tmRNA/rRNA neighborhoods plus optional serine-integrase CDS hotspots such as groL/groEL and any optional indexed global chunks, instead of parsing the full bacterial GenBank file.

False negatives can occur when the integrase is misannotated, when attP is far from the integrase, when the host genome is incomplete, when the true host is different from the supplied bacterium, or when the shared core is short/diverged. False positives can occur in repetitive sequence, conserved tRNAs, mobile elements, or low-complexity regions.
