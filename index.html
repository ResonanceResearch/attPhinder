attP / attB Finder

Drop annotated phage GenBank files and host bacterial genomes to predict candidate phage attP and host attB sites near tRNAs and across the broader chromosome.

Static GitHub Pages app No server upload. Files are parsed in your browser.

1. Input files

Phage files should preferably be annotated GenBank files containing an integrase CDS. Bacterial files can be GenBank or FASTA; GenBank is needed for tRNA-first screening. Large bacterial GenBank files are parsed in host-optimized mode so the browser does not need to load every bacterial CDS feature.

2. Analysis settings

The score combines exact shared core length, k-mer support, tRNA proximity, and whether the match is in the expected integrase-proximal phage window. It is a prioritization score, not experimental proof. For very large host genomes, keep “Maximum global candidates” modest or turn off broader search for a fast tRNA-first run.

How to interpret this

High-confidence candidates usually have a clear exact core match of roughly 20–50 bp between the phage integrase-proximal region and a bacterial locus, often overlapping or immediately adjacent to a tRNA. Temperate mycobacteriophages and many other phages integrate at tRNA loci, but not all do.

Large bacterial GenBank files are handled in a memory-conscious way: for host files the app parses the genome sequence and only tRNA/tmRNA features, not every CDS. If the host file is still slow, export the host genome as FASTA for global-only screening, or use a GenBank file when tRNA-first screening is essential.

False negatives can occur when the integrase is misannotated, when attP is far from the integrase, when the host genome is incomplete, when the true host is different from the supplied bacterium, or when the shared core is short/diverged. False positives can occur in repetitive sequence, conserved tRNAs, mobile elements, or low-complexity regions.
